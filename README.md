# Выравнивание мониторов

Программа для Windows, которая помогает точно выставить взаимное положение мониторов, чтобы курсор и окна переходили с одного экрана на другой без скачка по высоте.

Стандартные настройки Windows двигают мониторы грубо и не учитывают, что у разных мониторов разная плотность пикселей. Здесь положение задаётся с точностью до пикселя, а на самих экранах вдоль стыков рисуются миллиметровые линейки.

## Возможности

- Схема всех мониторов: перетаскивание мышью с прилипанием к краям (Alt отключает прилипание), масштаб колесом, правая кнопка двигает вид.
- Сдвиг выбранного монитора стрелками на 1, 5, 10 пикселей или примерно на 1 мм, с Shift в 10 раз больше. Координаты можно ввести числом.
- Физический размер экрана берётся из EDID монитора. Его можно поправить вручную, значение запоминается.
- Линейки на экранах вдоль каждого стыка: деления через 1 мм, красный ноль и жёлтая отметка курсора. Когда мониторы выставлены правильно, деления с одинаковыми числами по обе стороны стыка стоят на одной высоте.
- Линейку на экране можно тянуть мышью: монитор сдвигается вслед за ней, сдвиг в пикселях и миллиметрах виден прямо на линейке. Колесо мыши над линейкой сдвигает на 1 пиксель, с Shift на 10. Пока линейки включены, сквозь них нельзя кликнуть, выключаются они переключателем.
- Для каждого стыка видно, на сколько миллиметров один экран смещён относительно другого. Кнопки «верх», «центр», «низ» выравнивают края, а поле «Измерено» подгоняет положение под смещение, измеренное обычной линейкой.
- Режим «Применять сразу»: каждый сдвиг тут же применяется в Windows, линейки сразу показывают результат.
- Кнопка «Как было при запуске» возвращает исходную раскладку.

## Как пользоваться

1. Запустите программу, включите «Линейки на экранах».
2. Проверьте размеры экранов в миллиметрах. EDID часто округляет их, для точности измерьте видимую область рулеткой и введите.
3. Выберите монитор и двигайте его стрелками или тяните саму линейку на экране, пока деления по обе стороны стыка не совпадут. Удобно включить «Применять сразу».
4. Если плотность пикселей у мониторов разная, совпасть по всей длине стыка деления не могут. Тогда в «Ноль линеек» выберите точку, где переход должен быть идеальным: начало, центр или конец стыка.

Настройки хранятся в `%APPDATA%\MonitorAligner\config.json`.

## Сборка

Нужен Rust (stable, MSVC).

```bash
cargo build --release
```

Готовый файл: `target\release\monitor-aligner.exe`.
